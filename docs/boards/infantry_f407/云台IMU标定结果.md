# 步兵云台 IMU 标定结果

- **标定日期**：2026-11-12
- **硬件**：达妙 J4310 yaw + 云台侧六轴 IMU
- **采集方式**：USART1 @ 921600，10 Hz CAL 行，芯片复位后连续运行

## 一、坐标系定义（已确定）

```
IMU / 机体坐标系
  +X = 俯仰轴（枪管上下摆动的转轴）
  +Z = 竖直向上
  −Y = 枪管前方
```

满足右手系 `X × Y = Z`。

## 二、写入代码的标定值

| 项目 | 值 | 单位 |
|---|---|---|
| 枪管方向 `barrel_axis` | **(0, −1, 0)** | 机体坐标单位向量 |
| 安装矩阵 `install` | **单位阵** | — |
| 陀螺零偏 `gyro_bias_sensor` | **(−0.000251, +0.001645, +0.002211)** | rad/s |
| 水平投影阈值 `min_projection_squared` | **0.02** | — |
| 安装来源 `origin` | `measured` | — |

## 三、标定依据

| 姿态 | accel (x, y, z) | 说明 |
|---|---|---|
| 枪管 45° 向下 | (0.4495, **4.0812**, 8.8841) | 重力偏向 +Y |
| 枪管水平朝前 | (0.4170, **−0.4046**, 9.7674) | 重力集中在 +Z |
| 水平转 90° | (0.3576, −0.5288, 9.7602) | 绕竖直轴转，重力不变 |
| 枪管抬头 | (0.3142, **−5.3364**, 8.1483) | 重力偏向 −Y → **枪管沿 −Y** |

由 45°→水平 的重力变化反推旋转轴为 **(+0.999, −0.016, −0.043)**，几乎纯 +X，故 X 为俯仰轴。

## 四、验证结果

| 验证项 | 实测 | 判定 |
|---|---|---|
| 绕竖直轴转 90°：编码器 / IMU 航向 | 91.7° / 97.0° | 1:1 同向 |
| 静止重力模长 | 9.7749（理论 9.807） | 误差 0.33% |
| 水平时 roll / pitch | −0.011 / −0.033 rad | 接近零 |
| `heading` 输出 | −1.5438 rad | 链路生效 |
| `heading` 噪声 | sd 0.0023 rad（0.13°） | 平稳 |
| `reprime` 事件 | 0（20 s 内） | 无姿态重建 |

## 五、物理限制

**航向漂移**：短时实测 +1.32°/分钟（20 s）；40 s 静止实测约 9.0°/分钟。

六轴 IMU 无磁力计或视觉航向参考，该漂移无法通过软件消除，需外部航向参考才能根治。
