# 步兵稳向板级接入与观测

## 范围和当前状态

板级 `deployment_config()` 调用与主机测试同源的 `constexpr infantry_deployment_config()`。当前装配为 CAN1 C620 ID1–4 四轮、CAN1 TX/RX `0x005` 达妙 Yaw、CAN1 TX `0x001`／RX `0x011` 达妙 Pitch。Pitch 实物为 J4310，不是旧代码中的 M3508；CAN2 上的 `0x201`／`0x202` 不归属 Pitch。设备容量为九 DJI／两 DM，实际装配四 DJI／两 DM；协议域编号不变，部署摘要 layout=3。镜像审计同时核对数量和地址，帧上线本身不构成物理电机身份认证。

轮向、丝杆机械行程和动力学参数仍待标定。单云台 IMU 安装、枪管轴向及静态零偏已实测回填，Yaw 世界稳向和在线 PID 整定已接入；Pitch 按用户选择改为 MIT 电机侧位置闭环，移除 IMU 角度保持外环。板级 Yaw 目标变化率为 1.5 rad/s，Pitch 电机位置目标变化率上限为 0.806342 rad/s，普通／小陀螺共用线性映射；底盘与键鼠量程仍为零。**镜像不是硬隔离的“绝不发动力命令”固件**：已配置域仍有业务/维护命令路径，观测阶段也必须遵守物理急停和单独上电授权。

2026-11-12 的启动补偿版本已完成 ARM 编译、镜像审计和主机测试，并在用户授权、确认停止态后烧录。Flash 实际加载布局的 215,984 字节校验通过；复位后串口回读确认人工停止、无持权、各域不执行，补偿幅值与正弦幅值均为 0。该次烧录后 PID 回到当时默认 angle Kp=2、speed Kp=0.35。2026-11-14 用户确认关闭补偿后的遥控手感，本次源码默认改为 angle Kp=3、speed Kp=0.6，两环 Ki/Kd=0，补偿 F=0，原 ±6 rad/s、±2 N·m 限幅不变；烧录及回读状态以本次验证记录为准。

## 构建

工作区需具备 ARM GCC、Ninja、Python、STM32CubeF4 v1.28.3 对应源文件。SDK 元数据 pin 在 `sdk.cmake`，仅验证元数据不表示全部源码完整。

本次构建的 SDK 根为 `build/deps/STM32CubeF4-v1.28.3`：沿用已有 1.28.3 包的 package.xml、CMSIS 通用头和 FreeRTOS，补齐 ST 官方 v1.28.3 Git 树锁定的两个子模块：

- `stm32f4xx-hal-driver`：`b6f0ed3829f3829eb358a2e7417d80bba1a42db7`
- `cmsis-device-f4`：`3c77349ce04c8af401454cc51f85ea9a50e34fc1`

缺失的子模块从 STMicroelectronics 官方 GitHub 对应提交归档下载，经本机代理；没有修改原哨兵仓库的 SDK。上述依赖目录属于可重建构建产物，不入 Git。

在仓库根执行（先保证 SDK 完整）：

```sh
cmake -S . -B build/infantry-app-arm-Release -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_TOOLCHAIN_FILE="$PWD/cmake/arm-none-eabi.cmake" \
  -DARM_GNU_ROOT=/usr \
  -DEC_STM32CUBE_F4_ROOT="$PWD/build/deps/STM32CubeF4-v1.28.3" \
  -DEC_BUILD_INFANTRY_APP=ON -DEC_BUILD_INFANTRY_S1=OFF \
  -DEC_BUILD_INFANTRY_CAPTURE=OFF -DEC_BUILD_TESTS=OFF -DEC_BUILD_EXAMPLES=OFF \
  -DPython3_EXECUTABLE=/usr/bin/python3 -DEC_FIRMWARE_ID=infantry-observe
cmake --build build/infantry-app-arm-Release --target infantry_app
```

产物目录：`build/infantry-app-arm-Release/boards/infantry_f407/`，包含 `infantry_app.elf/.bin/.hex/.map`。链接后自动执行 `check_infantry_app.py` 检查镜像；该检查不会烧录。

## 丝杆 Pitch：MIT 电机位置闭环

电调始终保持 MIT 模式，本次只改变指令语义：位置目标为电机输出轴角（加关节零偏），速度目标与前馈力矩为零，MIT `Kp=20`、`Kd=0.5`。这两项是**待调值**，不是旧工程实测基线；旧 M3508 的 Kp=4.5（电流计数／转子deg/s）及注释中的 DM 参数不移植到本位置控制。

- 首次接管捕获新鲜电机位置，不跳到编码零点、不向电调写零位；推杆以 `轴值×方向×rate×dt` 改变位置目标，回中保持同一个目标。STOP、遥控失联、Pitch反馈失联后恢复时重新捕获当前位置，不恢复旧保持角。Yaw 世界稳向逻辑不变。
- Pitch 普通／小陀螺均为线性位置增量，变化率上限 46.2 deg/s（0.806342 rad/s，电机轴）。不再使用旧速度指令的 50/550 分段；沿既有 `stick_deadzone=0.05` 与回中接管策略。保持用户要求的反向效果：Yaw sign=-1；Pitch 原速度路径自带负号已删除，新位置路径 sign=+1，与旧 `(-raw)×(-1)` 物理同向。键鼠部署比例仍为零。
- 电机角不等于枪管俯仰角。2026-11-14 人工测得最低 `1.805333 rad`、最高 `2.875753 rad`，跨距 `1.070420 rad`；按用户要求两端各向外扩跨距 10%（`0.107042 rad`），Pitch 电机软件范围为 **`1.698291..2.982795 rad`**。外扩范围超过已测端点，机械行程尚未验证。MIT ±12.5 rad 只是编码窗口；改机械、换电机或改变位置零点必须重测端点。
- 遥控位置目标钳在该范围，上位机／维护越界请求整包拒绝。电机当前位置在范围外且有有效运行授权和位置目标时，采用最近的边界为目标，驱动电机返回；STOP、失联或电调故障时不执行返回。Pitch 不再使用 IMU 倾角限位。
- 双DM固件设备页为11槽（9 DJI容量+2 DM），APP载荷上限256 B。参数槽9为Yaw、槽10为Pitch（`0x0A01`=MIT Kp、`0x0A02`=Kd）；整车参数移至槽11（例如Yaw外环 `0x0B0A`、内环 `0x0B0D`）。旧槽10的整车参数不可按旧ID写入新固件，应重新枚举。

## yaw 独立 SWD 观测视图

`board_app.cpp` 导出全局符号 `g_ec_infantry_yaw`，类型在 `board_app_observation.h`。沿已有发布周期每 10 个控制周期更新一次（标称 100 Hz，实时性待实测）。不改变原 UART v3 的 214 字节快状态格式和监控注册表布局。

| 字段 | 含义 |
|---|---|
| `target_heading_rad` / `target_valid` | 应用实际采用的航向目标及存在性 |
| `measured_heading_rad` / `heading_rate_rad_s` / `imu_valid` | 校准后的云台世界航向、水平投影变化率及有效性 |
| `joint_angle_rad` / `joint_valid` | yaw 相对底盘的关节角及新鲜度；不是 IMU 世界角 |
| `imu_age_ms` / `joint_age_ms` | 对应反馈年龄；无效为 `0xffffffff` |
| `torque_command_nm` / `torque_submitted` | 采样到的当前控制周期电机侧力矩命令和 CAN 接口接受状态；不是实测力矩或送达确认 |
| `execute` / `reason` | 应用执行判定与原因编号 |
| `dm_online` / `dm_enabled` | 达妙新鲜反馈在线和使能确认 |
| `reference_epoch` | yaw 参考代次，重建后旧目标不可沿用 |
| `imu_estimated_yaw_rad` / `imu_gyro_z_rad_s` | 安装标定未完成也可查看的 IMU 估计输出，不能冒充云台已校准世界参考 |
| `imu_sample_valid` / `imu_sample_age_ms` | 上述 IMU 估计的有效性及年龄，与 `imu_valid` 分开 |

通过带符号 ELF 的调试器可查看 `g_ec_infantry_yaw`。非停机 SWD 读取时，在读取整个结构前后各读一次 `sequence`；仅接受前后相同的偶数，奇数表示更新中。所有数值必须结合有效位解读，零值不等于测量有效。这里未安装/启动探针，也未提供自动烧录动作。

## 云台摩擦启动补偿

仅作用于步兵 DM main_yaw 的世界稳向纯力矩路径。运动时使用**DM原生输出轴相对机构的机械速度**，不使用世界航向速率：底盘旋转而云台稳向时，世界速率可以为零，机械轴仍在转。静止时按角度误差的P项起动，不取速度环制动力矩或测量侧D项的符号。

设速度PID输出为 `u`（N·m），补偿幅值 `F`（N·m），速度平滑带 `V`（rad/s），DM反馈机械速度 `v_motor`（rad/s），电机方向映射 `s=torque_direction`（±1），最短弧角度误差 `e`（rad），当前实际生效的角度Kp为 `Kp_angle`：

```text
q = 2 × DM_VMAX / 4095                     # 12bit速度反馈的一个量化步长
m_motor = sign(v_motor) × clamp((abs(v_motor) - q) / V, 0, 1)
m = s × m_motor                           # 映射到世界力矩符号
start = clamp(Kp_angle × e / V, -1, +1)     # 仅静止起动项, 不含I/D
assist = F × (m + (1 - abs(m)) × start)
world_torque = clamp(u + assist, speed_pid.output_min, speed_pid.output_max)
motor_torque = s × world_torque
```

DM速度的对称量化在零点有半LSB偏移，`q`死区避免将该偏移当作真实运动并持续出力。速度超出死区后，在宽度 `V` 内连续交接；`abs(v_motor) >= q+V` 时补偿完全跟随机械运动方向。力矩方向与速度方向相同时，是补偿被动力学摩擦消耗的力矩，不是增加阻力。制动时PID仍负责净制动力矩；该补偿只是待验证的摩擦模型，幅值过大仍可能引起自激，不能承诺消除振荡。`F=0`时与未补偿输出一致。

| 参数 | ID | 固件默认值 | 在线范围 |
|---|---|---|---|
| `gimbal_friction_torque_nm` | `0x0B13`（槽 11，局部 19） | 0 N·m，关闭 | 0～DM 协议力矩上限（当前 10 N·m） |
| `gimbal_friction_speed_rad_s` | `0x0B14`（槽 11，局部 20） | 0.05 rad/s | 0.001～DM 协议速度上限（当前 30 rad/s） |

**兼容性变更：摩擦平滑参数不再是 `gimbal_friction_band_nm`，单位由N·m改为rad/s；双DM固件中其ID进一步从旧 `0x0A14` 移到 `0x0B14`。旧 `0x0A14` 现在属于Pitch零偏。不要按旧ID或旧单位回填；主机没有自动迁移，应先重新枚举参数。** 当前模型没有额外隐藏的起动力矩band。

`V=0.05` 是待整定的平滑设置，不是实测摩擦值；代码未预填 0.15/0.35 N·m 等经验摩擦幅值。即使配置更大的 `F`，叠加后的力矩仍受当前速度环限幅约束，部署默认仍为 **±2 N·m**，不因补偿而放宽。MIT 位置/速度 Kp/Kd 仍为零，现有使能、停止、反馈与 IMU 有效性检查不变。

通过既有参数协议读写，USART1 保持 **921600**；先将右拨杆置**中挡停止**，再写参数。遥控持权时的 `NOT_PERMITTED` 规则不变，不绕过权限。需要让参数协议独占串口时，使用当前 `telemetry_enable=0`（`0x0B12`），操作后恢复为 1。参数仅保存在 RAM，复位/烧录后重新读取默认值并回填已选定的 PID 基线，不自动保留此前在线调参。

验证补偿效果时，固定PID、正弦幅值与频率，先改变补偿模型或 `F` 中的一项，保留实际采纳目标、航向、DM反馈与提交力矩的采集记录。关闭补偿即可回到该版本的未补偿控制。主机测试验证机械/世界速度独立、静止量化不出力、起动/制动方向、符号映射、原限幅及参数读写；没有把实际stick-slip和振荡根因建模成已证明结论，新模型尚未验证实机带宽改善。烧录和有动力对照试验须另行授权，试验时物理急停就位。

## 验证

- 主机板级测试检查五 DJI/一 DM 地址、与共享装配工厂一致、Pitch 速度域完整及部署摇杆量程；应用/执行测试核对旧 Kp 换算、CAN2 `0x200` 首槽电流、回中零速度、多圈不依赖位置参考、IMU X轴方向限位与反馈失效撤输出。非步兵位置语义及零量程禁用行为保留。
- 世界稳向合成闭环检查 MIT 帧力矩与观测力矩在编码量化容差内一致；IMU 停止后 `torque_submitted=false`，不展示历史力矩为本周期输出。
- ARM 镜像审计检查 `g_ec_infantry_yaw` 符号保留及真实 APP/CAN 路径、装配摘要、无合成配置。
- 尚需真机核对 IMU 安装和零偏、力矩符号、编码器反馈回绕、CAN 参数、轮向及 PID；此处离线检查不替代单轴台架调试。
