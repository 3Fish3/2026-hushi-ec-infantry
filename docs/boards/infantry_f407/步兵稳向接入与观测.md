# 步兵稳向板级接入与观测

## 范围和当前状态

板级 `deployment_config()` 现在调用与主机测试同源的 `constexpr infantry_deployment_config()`，不再使用空装配表。固件装配为 CAN1 C620 ID1–4 四轮、CAN2 C620 ID5 pitch、CAN1 TX/RX 0x005 达妙 yaw。原有九 DJI/一 DM 的存储容量与协议域编号不变，实际安装五 DJI/一 DM。镜像离线检查同时验证数量和地址。

装配参数参考旧步兵工程；轮向、零位和动力学参数仍待标定。单云台 IMU 安装、枪管轴向及静态零偏已实测回填，yaw 世界稳向和在线 PID 整定已接入；pitch 位置环仍缺项，不获得执行资格。板级 yaw 摇杆量程为 1.5 rad/s，底盘与键鼠量程仍为零，步兵挡位映射已经启用。**镜像不是硬隔离的“绝不发动力命令”固件**：已配置域仍有业务/维护命令路径，观测阶段也必须遵守物理急停和单独上电授权。

2026-11-12 的启动补偿版本已完成 ARM 编译、镜像审计和主机测试，并在用户授权、确认停止态后烧录。Flash 实际加载布局的 215,984 字节校验通过；复位后串口回读确认人工停止、无持权、各域不执行，补偿幅值与正弦幅值均为 0。当前 PID 回到固件默认 angle Kp=2、speed Kp=0.35。补偿效果待单独授权后的实车对照验证。

## 构建

工作区需具备 ARM GCC、Ninja、Python、STM32CubeF4 v1.28.3 对应源文件。SDK 元数据 pin 在 `sdk.cmake`，仅验证元数据不表示全部源码完整。

本次构建的 SDK 根为 `build/deps/STM32CubeF4-v1.28.3`：沿用已有 1.28.3 包的 package.xml、CMSIS 通用头和 FreeRTOS，补齐 ST 官方 v1.28.3 Git 树锁定的两个子模块：

- `stm32f4xx-hal-driver`：`b6f0ed3829f3829eb358a2e7417d80bba1a42db7`
- `cmsis-device-f4`：`3c77349ce04c8af401454cc51f85ea9a50e34fc1`

缺失的子模块从 STMicroelectronics 官方 GitHub 对应提交归档下载，经本机代理；没有修改原哨兵仓库的 SDK。上述依赖目录属于可重建构建产物，不入 Git。

在仓库根执行（先保证 SDK 完整）：

```sh
cmake -S . -B build/infantry-app-arm-Release -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_TOOLCHAIN_FILE="$PWD/cmake/arm-none-eabi.cmake" \
  -DARM_GNU_ROOT=/usr \
  -DEC_STM32CUBE_F4_ROOT="$PWD/build/deps/STM32CubeF4-v1.28.3" \
  -DEC_BUILD_INFANTRY_APP=ON -DEC_BUILD_INFANTRY_S1=OFF \
  -DEC_BUILD_INFANTRY_CAPTURE=OFF -DEC_BUILD_TESTS=OFF -DEC_BUILD_EXAMPLES=OFF \
  -DPython3_EXECUTABLE=/usr/bin/python3 -DEC_FIRMWARE_ID=infantry-observe
cmake --build build/infantry-app-arm-Release --target infantry_app
```

产物目录：`build/infantry-app-arm-Release/boards/infantry_f407/`，包含 `infantry_app.elf/.bin/.hex/.map`。链接后自动执行 `check_infantry_app.py` 检查镜像；该检查不会烧录。

## yaw 独立 SWD 观测视图

`board_app.cpp` 导出全局符号 `g_ec_infantry_yaw`，类型在 `board_app_observation.h`。沿已有发布周期每 10 个控制周期更新一次（标称 100 Hz，实时性待实测）。不改变原 UART v3 的 214 字节快状态格式和监控注册表布局。

| 字段 | 含义 |
|---|---|
| `target_heading_rad` / `target_valid` | 应用实际采用的航向目标及存在性 |
| `measured_heading_rad` / `heading_rate_rad_s` / `imu_valid` | 校准后的云台世界航向、水平投影变化率及有效性 |
| `joint_angle_rad` / `joint_valid` | yaw 相对底盘的关节角及新鲜度；不是 IMU 世界角 |
| `imu_age_ms` / `joint_age_ms` | 对应反馈年龄；无效为 `0xffffffff` |
| `torque_command_nm` / `torque_submitted` | 采样到的当前控制周期电机侧力矩命令和 CAN 接口接受状态；不是实测力矩或送达确认 |
| `execute` / `reason` | 应用执行判定与原因编号 |
| `dm_online` / `dm_enabled` | 达妙新鲜反馈在线和使能确认 |
| `reference_epoch` | yaw 参考代次，重建后旧目标不可沿用 |
| `imu_estimated_yaw_rad` / `imu_gyro_z_rad_s` | 安装标定未完成也可查看的 IMU 估计输出，不能冒充云台已校准世界参考 |
| `imu_sample_valid` / `imu_sample_age_ms` | 上述 IMU 估计的有效性及年龄，与 `imu_valid` 分开 |

通过带符号 ELF 的调试器可查看 `g_ec_infantry_yaw`。非停机 SWD 读取时，在读取整个结构前后各读一次 `sequence`；仅接受前后相同的偶数，奇数表示更新中。所有数值必须结合有效位解读，零值不等于测量有效。这里未安装/启动探针，也未提供自动烧录动作。

## 云台摩擦启动补偿

仅作用于步兵 DM main_yaw 的世界稳向纯力矩路径。设速度 PID 的输出为 `u`，补偿幅值为 `F`，过零平滑带为 `B`（均为 N·m）：

```text
assist = F × clamp(u / B, -1, +1)
world_torque = clamp(u + assist, speed_pid.output_min, speed_pid.output_max)
motor_torque = torque_direction × world_torque
```

补偿沿 PID 力矩需求方向帮助启动，不是沿测得世界速度的反方向增加阻力。需求过零时补偿连续归零；`F=0` 时与未加补偿的输出一致。使用力矩需求而非世界角速度，是因为小陀螺稳向时世界角速度接近零，电机相对底盘仍可能持续转动。这是启动助力策略，不是对电机相对运动摩擦的完整前馈模型；过零段相当于提高局部控制增益，效果和稳定性需实测比较。

| 参数 | ID | 固件默认值 | 在线范围 |
|---|---|---|---|
| `gimbal_friction_torque_nm` | `0x0A13`（槽 10，局部 19） | 0 N·m，关闭 | 0～DM 协议力矩上限（当前 10 N·m） |
| `gimbal_friction_band_nm` | `0x0A14`（槽 10，局部 20） | 0.05 N·m | 0.001～DM 协议力矩上限 |

`B=0.05` 是待整定的平滑设置，不是实测摩擦值；代码未预填 0.15 N·m 等经验摩擦幅值。即使配置更大的 `F`，叠加后的力矩仍受当前速度环限幅约束，部署默认仍为 **±2 N·m**，不因补偿而放宽。MIT 位置/速度 Kp/Kd 仍为零，现有使能、停止、反馈与 IMU 有效性检查不变。

通过既有参数协议读写，USART1 保持 **921600**；先将右拨杆置**中挡停止**，再写参数。遥控持权时的 `NOT_PERMITTED` 规则不变，不绕过权限。需要让参数协议独占串口时，沿用 `telemetry_enable=0`（`0x0A12`），操作后恢复为 1。参数仅保存在 RAM，复位/烧录后重新读取默认值并回填已选定的 PID 基线，不自动保留此前在线调参。

验证补偿效果时，固定 PID、正弦幅值与频率，仅改变 `F`，保留未补偿/补偿后的 CAL 流作对照；先关闭补偿即可回到该版本的未补偿控制。静摩擦目前是待验证假设，主机测试检查的是参数与力矩执行契约，没有复现实际负载的 stick-slip，也未验证实机带宽提升。烧录和有动力对照试验须另行授权，试验时物理急停就位。

## 验证

- 主机板级测试检查五 DJI/一 DM 地址、与共享装配工厂一致、缺标定 yaw/pitch 不执行、零量程操纵不生成运动目标。
- 世界稳向合成闭环检查 MIT 帧力矩与观测力矩在编码量化容差内一致；IMU 停止后 `torque_submitted=false`，不展示历史力矩为本周期输出。
- ARM 镜像审计检查 `g_ec_infantry_yaw` 符号保留及真实 APP/CAN 路径、装配摘要、无合成配置。
- 尚需真机核对 IMU 安装和零偏、力矩符号、编码器反馈回绕、CAN 参数、轮向及 PID；此处离线检查不替代单轴台架调试。
